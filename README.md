# Sweet Sushi — меню

Адаптивный лендинг-меню для заведения в Мескере-Юрт. 68 позиций в 10 категориях. Корзина с количеством, суммой и подготовкой сообщения в WhatsApp. Оплаты и регистрации на сайте нет.

## Корзина и WhatsApp

Покупатель добавляет блюда, меняет количество и открывает корзину. Кнопка «Написать в WhatsApp» открывает чат с готовым списком, вариантами блюд и суммой. Посетитель отправляет сообщение самостоятельно; заказ и условия подтверждает кассир. Корзина сохраняется в браузере на устройстве.

Перед публикацией укажите публичный номер заведения в `assets/ordering-config.js`: международный формат, только цифры, начиная с кода страны. В `whatsappNumber` установлен предоставленный заказчиком номер заведения, тестовый режим отключён. Пока номер не задан, доступно копирование заказа, а переход в WhatsApp отключён. Сервер и токены не нужны.

У пяти холодных напитков не уточнены варианты для двух цен: они видны в меню, но пока не добавляются в корзину. Подробности: `docs/cart.md`.

## Локальный запуск

Нужен Node.js. Зависимостей нет, `npm install` не требуется.

```sh
node scripts/server.cjs
```

Откройте http://127.0.0.1:8766/ . Остановка — `Ctrl+C`. Повторный запуск — та же команда.

## Редактирование

- Названия, составы и цены: `docs/content.md`.
- Шаблон страницы и исходные стили: `scripts/build.cjs`.
- Оформление и адаптивность: `assets/styles.css`.
- Появление блоков и мобильная анимация: `assets/motion.js`.
- Изображение первого экрана: `assets/burger.jpg`.
- Локальный шрифт названий блюд: Oswald, `assets/fonts/oswald.ttf`; лицензия SIL OFL в той же папке. Источник — Google Fonts.
- Иконки категорий: Lucide, `assets/icons/`; лицензия сохранена в `assets/icons/LICENSE-LUCIDE.txt`.

После изменения меню или шаблона:

```sh
node scripts/build.cjs
node scripts/check.cjs
node scripts/test-cart.cjs
```

Готовый `index.html` включен в репозиторий. Правки CSS и JavaScript не требуют сборки.

## GitHub Pages

Загрузка кода в GitHub и публикация сайта — отдельные действия. Для публикации из репозитория откройте Settings → Pages, выберите Deploy from a branch, ветку `main` и папку `/ (root)`, сохраните. Дождитесь завершения развертывания; адрес появится в Pages. Доступность Pages зависит от настроек и плана аккаунта.

Все ссылки на ресурсы относительные: сайт можно разместить по адресу репозитория `/burger/` или в корне домена. Node.js на хостинге не нужен.

## Другой хостинг

Загрузите `index.html` и папку `assets/` с сохранением структуры. `scripts/`, `docs/` и `package.json` серверу для работы сайта не нужны.

## Поведение на телефоне

До 700 px бургер становится компактным фоновым элементом справа, при прокрутке слегка уменьшается. Поддерживается `prefers-reduced-motion`. Чёрный фон JPG совмещен с фоном страницы средствами CSS; у файла нет альфа-прозрачности.

## Материалы и статус

Это демонстрация для потенциального клиента. Контакты и часы работы пока не указаны. Название Sweet Sushi взято из материалов меню; финальное написание следует подтвердить у заведения. Текущий логотип — текстовый.

Цены и позиции перенесены с пяти листов меню, актуальность подтверждена заказчиком демонстрации. У холодных напитков две цены без подписанных объёмов: объёмы не выдуманы.

Изображение бургера предоставлено пользователем файлом `2151846494.jpg`; автор и лицензия не передавались. Лицензия на использование этого изображения не предоставляется данным репозиторием. Старые изображения с водяными знаками, сторонние референсы, скриншоты и неиспользуемая библиотека Three.js в репозиторий не включены.
