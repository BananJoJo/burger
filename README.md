# Sweet Sushi — меню

Адаптивный демонстрационный лендинг-меню для заведения в Мескере-Юрт. 68 позиций в 10 категориях. Без корзины, оплаты, форм и сбора заявок.

## Локальный запуск

Нужен Node.js. Зависимостей нет, `npm install` не требуется.

```sh
node scripts/server.cjs
```

Откройте http://127.0.0.1:8766/ . Остановка — `Ctrl+C`. Повторный запуск — та же команда.

## Редактирование

- Названия, составы и цены: `docs/content.md`.
- Шаблон страницы и исходные стили: `scripts/build.cjs`.
- Оформление и адаптивность: `assets/styles.css`.
- Появление блоков и мобильная анимация: `assets/motion.js`.
- Изображение первого экрана: `assets/burger.jpg`.

После изменения меню или шаблона:

```sh
node scripts/build.cjs
node scripts/check.cjs
```

Готовый `index.html` включен в репозиторий. Правки CSS и JavaScript не требуют сборки.

## GitHub Pages

Загрузка кода в GitHub и публикация сайта — отдельные действия. Для публикации из репозитория откройте Settings → Pages, выберите Deploy from a branch, ветку `main` и папку `/ (root)`, сохраните. Дождитесь завершения развертывания; адрес появится в Pages. Доступность Pages зависит от настроек и плана аккаунта.

Все ссылки на ресурсы относительные: сайт можно разместить по адресу репозитория `/burger/` или в корне домена. Node.js на хостинге не нужен.

## Другой хостинг

Загрузите `index.html` и папку `assets/` с сохранением структуры. `scripts/`, `docs/` и `package.json` серверу для работы сайта не нужны.

## Поведение на телефоне

До 700 px бургер становится компактным фоновым элементом справа, при прокрутке слегка уменьшается. Есть кнопка паузы и поддержка `prefers-reduced-motion`. Чёрный фон JPG совмещен с фоном страницы средствами CSS; у файла нет альфа-прозрачности.

## Материалы и статус

Это демонстрация для потенциального клиента. Контакты и часы работы пока не указаны. Название Sweet Sushi взято из материалов меню; финальное написание следует подтвердить у заведения. Текущий логотип — текстовый.

Цены и позиции перенесены с пяти листов меню, актуальность подтверждена заказчиком демонстрации. У холодных напитков две цены без подписанных объёмов: объёмы не выдуманы.
